# Phase 02 – Research & Validation

## Goal
Turn ranked candidates into a sourced validation report with clear Truth statuses and a GO / CONDITIONAL GO / NO GO recommendation.

## Entry Criteria
- Discovery status exists

## Process
1. Take the top 3–5 candidates
2. For each: market demand, competition, technical feasibility, rough unit economics, legal flags
3. Assign Truth status to every important claim
4. Produce `status/validation_report.md` and `status/claims_with_status.md`
5. Stop for Human Checkpoint 1

## Exit Criteria
- Validation report exists
- Human has given direction (GO / adjust / stop)
