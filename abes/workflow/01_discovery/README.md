# Phase 01 – Discovery

## Goal
Generate a ranked list of realistic business opportunities based on the user’s preferences and constraints.

## Entry Criteria
- `knowledge/00_preferences.md` is filled

## Process
1. Read `knowledge/00_preferences.md` and any other files in `knowledge/`
2. Generate 8–15 candidate ideas
3. Rank them by fit to constraints, automatability, and realism
4. Write output to `status/discovery_status.md`

## Exit Criteria
- `status/discovery_status.md` exists and contains ranked candidates
- User has reviewed it (or AI has asked for confirmation)

## Next Phase
Research & Validation on the top candidates
